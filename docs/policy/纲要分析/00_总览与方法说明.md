# 00 总览与方法说明

## 这份分析是什么、不是什么

**是什么**：把《中华人民共和国国民经济和社会发展第十五个五年规划纲要》当作一份"未来五年的国家行为蓝图"来读，从中提取对一个具体的人（中西部上班族，关注互联网+体制内两条赛道，最关心职业发展和养老医疗）有用的判断。

**不是什么**：不是逐章精读笔记（那份在 `../建议/` 目录下，应试用），不是政治理论解读，不是泛泛而谈的"X个看点"。

## 两份文件的关系

| 维度 | 建议 | 纲要 |
|---|---|---|
| 发布时间 | 2025-10-23 | 2026-03-13 |
| 通过机构 | 二十届四中全会 | 十四届全国人大四次会议 |
| 性质 | 党中央政治指导文件 | 国务院执行规划，有法律效力 |
| 结构 | 15章61条 | 18篇62章 |
| 字数 | 约2.5万字 | 约8万字 |
| 量化指标 | 几乎没有 | 20+个具体数字 |
| 落地度 | 方向性 | 操作性（含工程清单、责任机制） |

**关键判断**：建议是"想做什么"，纲要是"准备怎么做"。中间4个多月的博弈和细化结果，藏着真正的优先级和政策力度判断。

## 阅读路径

按顺序读最合理，但每份独立也成立：

1. **01_建议vs纲要_关键差异** — 这份独家价值最高。市面解读基本是直接解读纲要内容；通过对比两版本能看出 *真正* 被加码、被收紧、被新增的东西。
2. **02_行业风口与投资主题** — 哪些行业 5 年内顺风、哪些逆风、有哪些可执行的投资主题（不是个股推荐，是大方向）。
3. **03_区域格局与城市选择** — 中西部到底在国家版图里是什么定位，哪些中西部城市值得长期看好。
4. **04_上班族个人启示** — 把前面的判断翻译成"对你这种身份的人意味着什么"，集中讲互联网/体制内职业判断 + 养老医疗规划。
5. **05_未来5年行动清单** — 不再讲道理，只列今年/明年/3年内/5年内分别该做什么。

## 用法建议

- 政策文件不是预言，是"政府想往哪推的力"。你应该把它当成判断未来5年风向的输入之一，不是唯一。
- 量化指标更可信（写进纲要的数字一般会兑现，因为要向人大报告），定性目标更易打折扣。
- 区域和产业的"重点提及"不一定意味着马上发生，但意味着资金、政策、关注度会优先到位。
- 你最该问自己的问题：**未来5年，我的工作/资产/家庭安排，是顺着这股力还是逆着这股力？**

## 这份分析的局限

- 纲要只发布2个月（2026/03→05），后续配套政策、地方实施方案还会陆续出来，本分析只能基于纲要本身。
- 不构成投资建议、就业建议、地产建议。判断政策方向 ≠ 判断市场反应。市场可能 *已经* 把利好定价进去了。
- 政策有不确定性。外部环境（中美关系、地缘）变化会改变优先级。
- 我（Claude）是工具，最终决策权在你。看完后建议带着具体问题再来对话，不要照单全收。
