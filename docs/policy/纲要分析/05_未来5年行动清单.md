# 05 未来 5 年行动清单

> 把前面 4 份分析的所有结论翻译成"你该做什么"。按时间分层。不讲理由（理由在前面 4 份里），只列动作。

---

## 🔴 立刻做（本月内 / 一周内）

### 财务/制度红利（不做就亏）
- [ ] **开个人养老金账户**（如果还没开）。每年 12000 额度税前扣除，按你的工资和税率，省 1500-3000 元/年起。中长期复利+税延效应巨大
- [ ] **检查公司是否有企业年金 / 单位是否有职业年金**。如果有，确认参缴；如果没有，未来谈薪资可以问
- [ ] **检查所在城市是否纳入长期护理保险试点**（如纳入：父母+你自己都要参保）
- [ ] **配置百万医疗险**（如尚未配置）。30-40岁年保费几百块，每年续保，保到 70+
- [ ] **配置重疾险**（如尚未配置）。每年保费几千到一万出头，越年轻越便宜
- [ ] **配置定期寿险**（如有家庭责任）。三五百万保额年保费几千

### AI/技能预热
- [ ] **每天至少 1 小时高强度使用 AI 工具**（不是聊天，而是用 ChatGPT/Claude/通义/文心/DeepSeek 处理实际工作）
- [ ] **关注 1-2 个高质量 AI 资讯渠道**（避免概念党，关注实际应用案例）

### 信息源
- [ ] **关注当地政府的"十五五"专项规划**（一般 2026 年内陆续发布，省级、市级各有版本）
- [ ] **订阅 1-2 个高质量政策解读账号**（避免标题党、概念党）
- [ ] **保存《纲要》原文 + 这份分析作为长期参考**

## 🟠 今年内（2026 剩余时间）

### 职业
- [ ] **梳理自己未来 5 年的 "深度+广度" 能力图谱**：哪一个细分领域是你的护城河？广度上你能跨到哪些方向？
- [ ] **如果在互联网行业**：评估自己当前业务的 AI 化进度。如果 1 年内仍未引入 AI、未做 B 端/出海准备，要考虑主动转型或预备外部机会
- [ ] **如果在体制内**：评估自己的"数字化能力 + 专业能力 + 政治素养"三角形是否均衡
- [ ] **盘点身边的 AI 实践者 / 出海实践者 / 政企转型者**，建立 5-10 人的信息圈
- [ ] **更新简历 + LinkedIn / 脉脉 / 求职平台档案**（不一定要跳槽，但要保持可见度）

### 财务
- [ ] **个税专项附加扣除**：检查是否所有可扣项目都已申报（子女教育、继续教育、大病医疗、住房贷款利息/租金、赡养老人、婴幼儿照护、3岁以下子女）
- [ ] **如有孩子在 0-3 岁**：申请育儿补贴（现已全国实施）
- [ ] **梳理家庭资产负债表**：现金、定期、基金、股票、房产、车贷、房贷分项列清
- [ ] **建立 6-12 个月生活费的应急储备金**（货币基金 / 短债基金）

### 父母养老
- [ ] **了解父母户籍地的长期护理保险政策**（如已试点，让他们参保）
- [ ] **办好父母异地就医备案**（如未来可能到你所在城市就医）
- [ ] **了解父母慢性病在当地的医保门诊统筹政策**
- [ ] **督促父母参加社区免费体检 / 慢病筛查**
- [ ] **检查父母的基础养老金/职工养老金的最新政策**

### 住房（如有考虑）
- [ ] **不急于在 2026 年买房**。"加快构建房地产发展新模式"+ 现房销售推进 + 城市分化加剧 = 现在不是急购窗口
- [ ] **如有改善需求，关注现房 / 准现房项目**，不优先选纯期房
- [ ] **如在中西部省会 / 都市圈中心**：关注核心地段 + 优质学区 / 医疗 / 通勤的二手房
- [ ] **不要在人口流出 + 主导产业逆风的城市加大房产敞口**

### 子女教育（如有孩子）
- [ ] **关注当地公办幼儿园 / 普惠托育资源新增情况**
- [ ] **了解所在城市的中考改革进度**（"优质高中招生指标到校"）
- [ ] **如孩子初高中**：理工方向 vs 文方向的取舍要更倾向理工（特别是 AI、半导体、生物、新能源相关）

## 🟡 明年内（2027）

### 职业
- [ ] **完成 AI 工具从"会用"到"重构工作流"的进化**。能够用 AI 把自己一天 2-4 小时的工作压缩到 30 分钟以内
- [ ] **如在互联网行业**：要么晋升到业务核心岗（产品/技术/业务负责人），要么完成转型探索（B 端、政企、出海、独立项目其中之一）
- [ ] **如在体制内**：争取一次轮岗 / 挂职 / 学习深造的机会。"基层经历 + 数字化能力"组合是后续晋升的差异化资本
- [ ] **学一个跨行业能力**：英语提升 / 法律基础 / 财务基础 / 数据分析 — 选你最缺的一个

### 财务
- [ ] **个人养老金账户开始正式定投**（如开了未配置，今年要开始投，不要让额度作废）
- [ ] **建立家庭"4321"资产配置框架**：40% 长期投资（指数基金 + 养老金）、30% 现金 / 短债、20% 保险、10% 应急（具体比例按个人调整）
- [ ] **考虑配置一份中端医疗险**（如经济允许）—— 创新药纳入商保支付范围后价值上升

### 父母养老
- [ ] **如父母接近退休**：彻底搞清楚延迟退休具体到他们的执行时间表
- [ ] **如父母失能/半失能风险开始增加**：提前了解居家适老化改造补贴 + 社区嵌入式养老服务 + 医养结合机构
- [ ] **关注当地"社区嵌入式服务"和"15 分钟便民生活圈"建设进度**

### 自己医疗
- [ ] **完成一次 30+ 全面体检**（含胃肠镜、心脑血管、肿瘤标志物）
- [ ] **如有家族病史**：建立专项体检计划

### 城市/居住
- [ ] **如果在人口流出 + 产业单一的中小城市**：开始认真评估是否在 2027-2028 年迁往省会 / 都市圈中心
- [ ] **如果在中西部省会**：享受都市圈红利，不要轻易离开
- [ ] **关注当地"高等教育资源向中西部倾斜"的实际落地**（新建大学 / 新增学院 / 扩招专业）

### 子女
- [ ] **如孩子在小升初 / 中考阶段**：研究当地"指标到校 + 均衡派位"政策
- [ ] **如孩子在高考前**：理工类 + 中西部高校选项扩大，可重新评估志愿策略

## 🟢 3 年内（到 2028 年底）

### 职业
- [ ] **完成一次主动的职业升级或转型**（不是被动跳槽，而是有规划的升级）
- [ ] **建立 1-2 个真正能拿出来的"作品"或"标杆项目"**：能写在简历上、能在面试时拿出来讲、能让陌生人看一眼就知道你做过什么
- [ ] **构建一个轻量级的"个人 IP"或专业社群**（不一定做自媒体，但要在专业圈子里有一定影响）
- [ ] **互联网行业**：如果一直在大厂中层徘徊且没有晋升路径，3 年内要做决断
- [ ] **体制内**：如果一直在非核心岗位且无突破，3 年内要主动争取调岗

### 财务
- [ ] **个人养老金账户累计投入 3-4 万 + 投资收益**
- [ ] **应急储备金 + 短债基金达到 1 年生活费规模**
- [ ] **完成 1 次家庭资产再平衡**（每 1-2 年一次）

### 父母养老
- [ ] **如父母 65+**：完成居家适老化改造（很多地方有补贴）
- [ ] **建立父母的"医疗+养老+护理"应急预案**：如果突发重病/失能，钱怎么出、谁来照顾、机构怎么选 — 想清楚再写下来

### 子女教育
- [ ] **如孩子在小学**：关注当地"小班化教学"试点的落地情况
- [ ] **如孩子在初中**：关注"高中阶段教育完成率 88%"目标下的中考改革
- [ ] **如孩子已上大学**：关注"工程硕博士培养比重提高"对其考研选择的影响

### 资产配置
- [ ] **A 股: 默认低成本宽基指数定投** + 少量主题（AI 算力、创新药、新能源 等不超过 20%）
- [ ] **港股 / 海外**：如有渠道，配置一定比例的恒生科技 / 全球 / 美股
- [ ] **不增持非核心城市房产**

---

## 🔵 5 年内（到 2030 年底）

### 职业
- [ ] **40 岁前后：完成职业生涯的"中场转换"**。要么进入管理 / 业务核心层，要么完成专业化深耕（成为某细分领域的专家），要么完成跨界转型（互联网→政企 / 实业 / 出海 / 独立顾问）
- [ ] **建立一个"非工资收入"管道**：投资收益 / 副业 / 顾问 / 出海项目 / 写作 / 教学等任选其一
- [ ] **如自己创业**：评估是否能借十五五的政策红利（AI / 银发 / 出海 / 数据要素 / 普惠托育 等）

### 财务
- [ ] **个人养老金账户累计投入 6 万 + 投资收益**
- [ ] **家庭可投资资产达到家庭年支出的 5-8 倍**（这是 "FI" 概念里的初阶财务安全线，不是退休，但已可承受较大波动）
- [ ] **完成商业养老保险长期配置**（叠加在个人养老金之上）

### 父母养老
- [ ] **完成父母养老的长期规划**：居家 vs 机构 / 异地 vs 本地 / 单方面承担 vs 兄弟姐妹共担 — 与家人达成共识

### 自己健康
- [ ] **40+ 启动"健康投资"系统**：每年体检 + 慢病管理 + 体重控制 + 运动 + 心理（"经常体育锻炼人数比例 40%"，你应该在这 40% 里）

### 住房
- [ ] **完成"刚需 + 改善"基本需求**（不再额外加房产敞口）
- [ ] **如所在城市适老化改造 / 城市更新启动**：评估自有房产的更新机会

### 子女教育
- [ ] **如孩子在高考阶段**：根据"工程硕博士培养比重提高""新增高教资源向中西部倾斜"的实际落地选择路径
- [ ] **如孩子在大学**：理工科 + 国家战略需求专业（AI、集成电路、生物医药、新能源、航空航天）+ 跨学科是优选

## ⚪ 时刻提醒（无时间限制）

- 政策是输入，不是预言。要用、不要信。
- 行动比信息重要。看 100 篇分析不如做 1 个改变。
- 任何 5 年规划都要每年 review，按实际情况调整。外部不确定性大，规划要韧性。
- 别为追"风口"牺牲基本面。家庭、健康、关系、技能，永远是最稳的资产。
- 政策有时差。从纲要到具体政策到落地，需要 6-24 个月。第一波红利往往属于"提前看见 + 早做准备"的人。
- **不要把这份分析当作神谕**。你比我更了解自己的实际处境。我能给的是框架和参考，不是答案。

## 📋 一页纸"今天就做"

如果你只有 1 小时去做事，做这 5 件：

1. **开个人养老金账户**（任意大行 APP，5 分钟）— 年省 1500-3000 税 + 长期复利
2. **配置百万医疗险**（支付宝 / 微信 / 平安 / 太保等比较，30 分钟）— 几百块年保费换百万医疗保障
3. **保存这份分析的所有 6 个 .md 文件到云盘 / 备忘录**（5 分钟）— 半年后回看
4. **今晚和家人讨论一次"5 年规划"**（30 分钟）— 父母养老、子女教育、住房、自己职业方向
5. **打开 AI 工具，用它处理一件今天必须做的工作**（20 分钟）— 不要让 AI 仅是聊天对象
