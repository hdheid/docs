# 01 建议 vs 纲要：关键差异

> 这份分析的核心。建议（2025-10）是"想做什么"，纲要（2026-03）是"准备怎么做"。中间4个多月的博弈+细化，反映了真正被加码的优先级。

## 一、结构性升格 — 被独立成"篇"的领域

| 在建议中是 | 在纲要中升格为 | 信号 |
|---|---|---|
| 第14条（科技章下面1条） | **第四篇 数字中国**（3章9节） | 数字经济/AI从"科技分支"升为国家战略主轴 |
| 第11章（民生章下含人口） | **第十一篇 人口发展战略**（4章） | 人口问题从民生议题升为独立战略 |
| 第57条（团结奋斗章下） | **第十六篇 全过程人民民主** | 民主+法治独立成篇 |
| 第58-59条（团结奋斗章下） | **第十七篇 一国两制 推进祖国统一** | 港澳台问题独立成篇，分量加重 |
| 第7章（市场经济章下） | **第六篇 高水平社会主义市场经济**（独立） | 与建议结构基本一致 |

**怎么读这个**：政策文本结构权重 ≈ 政治权重。"独立成篇" 意味着这个领域在未来 5 年要单独抓、单独考核、单独配资源。

升格信号最值得注意的是 **数字中国/AI**：建议里只是科技章下一个条款，纲要里成了与"现代化产业体系"并列的国家战略支柱。"人工智能+"在纲要中出现 20 多次，是建议的几倍。

## 二、量化指标加码 — 建议没数字，纲要给硬指标

建议几乎完全是定性表述。纲要明确写入下列指标，写进纲要意味着 5 年后要向人大报告完成情况。这是真正的"承诺"：

### 经济与科技
| 指标 | 纲要目标 | 十四五对照 |
|---|---|---|
| GDP 增速 | "合理区间、各年度视情提出" | 比"十四五"更模糊，意味着实际增速可能在 4-5% 区间 |
| 研发经费投入 | 年均增长 7%以上 | 十四五是2.8%的强度 |
| 城镇调查失业率 | <5.5% | 不算激进 |
| 居民消费率 | 明显提高（无具体数） | 软指标 |

### 教育与人口
| 指标 | 纲要目标 | 解读 |
|---|---|---|
| 劳动年龄人口平均受教育年限 | 11.7年 | 十四五是11.3，5年+0.4年算稳进 |
| 学前教育毛入园率 | 95% | 普惠托育大推进 |
| 高中阶段教育完成率 | 88% | 含中职 |
| 高等教育毛入学率 | 65% | 大学普及化继续 |
| 工程硕博士培养比重 | 大幅提高（无具体数） | 倾斜理工科 |
| 人均预期寿命 | 80岁 | 十四五79+，温和提升 |
| 婴儿死亡率 | <3.5‰ | 十四五目标已接近 |
| 孕产妇死亡率 | <12/10万 | 同上 |
| 重大慢性病过早死亡率 | <13% | 健康中国硬指标 |
| 经常体育锻炼人数比例 | 40%左右 | 配合健康中国 |

### 绿色与资源
| 指标 | 纲要目标 | 解读 |
|---|---|---|
| 单位GDP CO2 排放 | 降低 17% | 十四五原目标是18%，略降 |
| 单位GDP 能耗 | 降低 10%左右 | 比十四五的13.5%大幅放松 |
| 单位GDP 用水量 | 下降 10% | |
| PM2.5（地级及以上城市） | <27 μg/m³ | 十四五终点是28，微降 |
| 优良水体比例 | ≥85% | 十四五是85%，持平 |
| 森林覆盖率 | 25.8% | 十四五是25%，缓增 |
| 森林蓄积量 | 224亿立方米 | |
| 新增建设用地 | 控制在 2600万亩以内 | 总量管控 |
| 大宗固废年利用量 | 45亿吨左右 | |

### 农业与能源安全
| 指标 | 纲要目标 | 解读 |
|---|---|---|
| 粮食综合生产能力 | 1.45万亿斤左右 | 十四五是1.4万亿斤，多500亿斤 |
| 能源综合生产能力 | 58亿吨标准煤 | 兜底产能 |
| 原油年产量 | 稳定在 2亿吨左右 | 罕见地点名"原油"具体数 |
| 农作物耕种收综合机械化率 | >80% | |
| 近岸海域优良水质 | 86%左右 | 海洋治理新加码 |
| 农田灌溉水有效利用系数 | 0.6 | |

### 海洋（新指标领域）
| 指标 | 纲要目标 |
|---|---|
| 大陆自然岸线保有率 | ≥35% |
| 近岸海域优良水质比例 | 86%左右 |

**怎么读这些数字**：
- **单位GDP 能耗目标从十四五的13.5%放松到10%**：透露重要信号 — "能耗双控"让位于"碳排放双控"，能源安全和经济增长的优先级在重排。这对煤电、化工、钢铁等高耗能行业是边际利好。
- **单位 GDP CO2 排放降17%**：比能耗下降目标高，意味着能源结构必须更快脱碳（绿电替代加速）。
- **粮食产能再提500亿斤**：种业、智慧农业、高标准农田会持续有政策资源。
- **原油2亿吨"稳定"**：明示国内原油产量已到顶，未来更多靠进口多元化+战略储备。

## 三、措辞强度变化 — 哪里加码、哪里收紧

### 加码（建议→纲要 力度变强）

| 领域 | 建议措辞 | 纲要措辞 | 解读 |
|---|---|---|---|
| 房地产新模式 | "健全房地产发展新模式" | "**加快构建**房地产发展新模式" | 提速 |
| 房地产融资 | "完善商品房开发、融资、销售等基础制度" | 增加"推行房地产开发**项目公司制**和**融资主办银行制**"、"**有力有序推进现房销售**" | 具体工具 |
| 长期护理保险 | "推行长期护理保险" | "推行长期护理保险，**健全统一的老年人能力评估制度**" | 制度配套 |
| 个人养老金 | "加快发展多层次、多支柱养老保险体系" | "完善**个人养老金政策**，大力发展**商业养老保险**" | 第三支柱实质化 |
| 生育支持 | "完善生育保险制度" | "基本实现**政策范围内住院分娩个人无自付**"、"将适宜的**分娩镇痛项目纳入保障**" | 真金白银 |
| 创新药 | "支持创新药和医疗器械发展" | "**完善创新药目录**，**鼓励商业保险扩大创新药支付范围**"、"高质量建设**债券市场科技板**" | 融资+支付双轮 |
| 城镇化落户 | "推行由常住地登记户口提供基本公共服务制度" | "**全面设立街道或社区公共户口**"、"完善超大特大城市积分落户政策" | 操作化 |
| 中西部都市圈 | 未明确提 | "**在中西部和东北地区培育若干都市圈**" | 重大新提法 |
| 高教资源分配 | 未提倾斜 | "**新增高等教育资源适度向人口大省和中西部地区倾斜**" | 中西部用户直接相关 |
| 平台经济 | "推动平台经济创新和健康发展" | 同上 + "促进平台企业和平台内**经营者、劳动者共赢发展**" | 含劳动者保护 |
| AI 治理 | "加强人工智能治理，完善相关法律法规、政策制度、应用规范、伦理准则" | 上述 + "推动建立**人工智能全生命周期风险管理制度**"、"**生成物权利归属和开发者经营者使用者权责认定规则**" | 治理细化 |
| 出海 | "引导产业链供应链合理有序跨境布局" | 同上 + "**鼓励互联网平台、人工智能等新兴产业企业拓展海外应用场景**" | 数字企业被点名 |

### 收紧（建议→纲要 力度变弱或限制变多）

| 领域 | 建议措辞 | 纲要措辞 | 解读 |
|---|---|---|---|
| 新型基础设施 | "适度超前建设新型基础设施" | "坚持**适度超前、不过度超前**" | 谨慎，避免重复建设 |
| 政府投资 | "保持投资合理增长" | 同上 + "**避免过度超前建设和低效无效投资**" | 警示信号 |
| 高耗能项目 | 一般性约束 | "**新建和改扩建高耗能高排放工业项目实施碳排放等量或减量置换**" | 新项目上马门槛抬高 |
| 内卷竞争 | "综合整治内卷式竞争" | 同上 + 反复强调 | 持续打击 |
| 招商引资 | 未明确 | "**制定地方政府招商引资鼓励和禁止事项清单**" | 限制地方政府无序竞争 |
| 反腐 | "反腐败永远在路上" | 同上 + "严查权力集中、**资金密集、资源富集领域**腐败"、"严查**政商勾连**" | 力度未减 |

## 四、新增内容（建议没提、纲要专门写）

### 经济安全单独成章（第五十二章）

建议有"国家安全屏障"等表述，但**没有像纲要这样把"经济安全"作为独立章节系统部署**。纲要明确列出：
- 粮食安全（产能数字、储备调节、海外供应渠道）
- 能源资源（原油 2 亿吨、天然气稳步增长、煤制油气产能储备）
- 战略性矿产（找矿突破战略行动、产品产能产地三储备）
- 防范化解房地产/地方债/中小金融机构风险（"长效机制"而非应急处置）
- 网络安全（关键信息基础设施、清朗专项）

**信号**：风险防控从"专项行动"上升为"长效制度"。地方债、房地产、中小银行三类风险还是中长期任务。

### 海洋经济（第三十二章）

建议有32条提海洋，但纲要给了完整章节，三节细化：
- 海洋经济高质量发展：远洋渔业、海洋装备、海洋生物医药、海水淡化
- 北部/东部/南部海洋经济圈布局
- 海洋生态保护与海洋权益维护

### 银发经济（第四十章）

建议提"发展银发经济"，纲要给具体抓手：
- 银发经济**龙头企业**和知名品牌
- 探索**银发产品认证制度**
- **银发经济统计**
- 信号：5 年内银发产业链会成型，含产品、服务、品牌、认证、统计标准

### 反内卷+合理利益分享

纲要新增："探索产业**转出地和承接地税收、用地和碳排放指标等利益分享机制**" — 这是为产业向中西部转移扫除地方利益障碍的关键配套。

## 五、未明说的优先级转移

把上面的变化合起来读，能看出一些建议中没直接讲、但纲要明显倾斜的方向：

### 1. 能源安全 > 能耗强度
- 单位 GDP 能耗下降目标从十四五的13.5%放松到10%
- 但 CO2 排放强度仍降17%
- 含义：少烧煤 ≠ 少耗能。可以多用电（哪怕来自新能源），但要烧得更"绿"

### 2. AI 是全篇主线，不止是科技章节
"人工智能+"覆盖：产业（智改数转）、生活（智能家居、智慧出行、教育医疗）、治理（政务服务、安全治理）、出海（鼓励 AI 企业海外应用场景）。

含义：AI 不是"一个产业"，是"一种全社会基础设施"。这跟"互联网+"在十三五的定位类似，但力度更大。

### 3. "中西部" 成为多个政策的承接地
- 高等教育资源倾斜
- 培育若干都市圈
- 中部地区粮食+能源原材料+装备制造
- 西部大开发"新格局"+ 西部陆海新通道
- 产业转移利益分享机制

含义：中西部不再只是"扶贫对象"，而是"承接东部产业+保障国家安全（粮食、能源、战略腹地）"的双重角色。

### 4. 民营经济和外资被多次重申
建议已经强调"两个毫不动摇"，纲要进一步给操作工具：
- 民营企业参与铁路、核电、水电、供水项目，提高持股比例
- 推动新兴领域应用场景向民营企业开放
- 全国一体化融资信用服务平台
- 营商环境：高效办成一件事、综合查一次、清理拖欠

外资：
- 增值电信、生物技术、外商独资医院开放试点
- 服务业重点扩开放
- 全口径外债监管

含义：在国内宏观承压、外资流出的背景下，政策上对市场主体的"安抚"力度比建议更大。

### 5. 房地产由"维稳" → "新模式建设"
- 项目公司制、融资主办银行制、现房销售（操作工具）
- 已供未开发土地分类处置
- 充分赋予城市政府调控自主权
- 加快构建（不再是"健全"）

含义：旧模式（高杠杆、预售制、土地财政）的退出路径更清晰。但"加快构建" + "因城施策"也意味着未来 5 年仍处于过渡期，不会一次性。

### 6. 反腐重点圈定
"严查权力集中、**资金密集、资源富集领域**腐败" — 这三个词组合起来通常指向：金融、国企、土地、采购、医药。体制内在这些条线的同志要格外注意。

## 六、最值得标红的5个变化（按优先级）

如果你只能记住5个变化：

1. **数字中国/AI升格为独立战略主轴**，未来5年是"AI+一切"。
2. **高等教育资源向中西部倾斜+培育中西部都市圈** — 中西部用户的子女教育和定居判断需要重新评估。
3. **个人养老金 + 商业养老保险 + 长期护理保险**三件套实质化 — 个人养老规划要主动配置。
4. **房地产"加快构建新模式"+ 现房销售+ 项目公司制** — 买新房逻辑会变。
5. **能源安全优先级超过能耗强度**，但碳排放仍要降 — 新能源继续加码，但传统能源不会突然退出。

## 七、政治信号备忘（非经济维度，供参考）

- "两个确立""两个维护""四个意识""四个自信"在建议和纲要中表述一致，无显著变化。
- "习近平新时代中国特色社会主义思想" 在纲要中提及频次和位置与建议保持一致。
- 全过程人民民主、一国两制 单独成篇 — 政治叙事的强化。
- "建军一百年"奋斗目标继续作为硬约束（2027年）。
- 民主法治篇内容与建议基本一致，无明显放松或加强。
