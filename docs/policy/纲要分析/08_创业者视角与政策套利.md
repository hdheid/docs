# 08 创业者视角与政策套利

> 把纲要从创业者/小老板的角度读：哪些细分赛道有政策红利、哪些套利空间可用、合规成本怎么变、钱从哪来、出海怎么走、什么坑必踩。

注意：这份文件不构成商业建议。每个赛道的实际盈利能力取决于团队、资金、时机、执行，远比"政策红利"复杂。

## 一、5 年内可借势的细分赛道

**政策抓手**：人工智能创新高地、应用中试基地、行业专用模型试点、"人工智能+"行动专项

## 二、政策套利空间

### 税收优惠
- **高新技术企业认定**：所得税 15%（标准 25%）。要点：研发费用占比、知识产权、科技人员占比
- **研发费用加计扣除**：100% 加计扣除常态化，部分行业可能再提高
- **科技型中小企业** + 研发费加计扣除组合
- **小微企业税收优惠**：年应纳税所得额 300 万元以下减按 5% 计征
- **西部大开发税收优惠**：西部地区企业 15% 所得税
- **海南自贸港**：鼓励类企业 15% 企业所得税 + 个税最高 15%
- **集成电路 + 软件企业**：所得税"两免三减半"等
- **创业投资基金税收政策**：投资中小科技型企业按 70% 抵扣
- **个人养老金账户**：12000 额度税前扣除

**怎么用**：如果创业，注册地选择 + 业务定性 + 财税合规要从一开始规划。专业财税顾问几千块/年的费用，能省几万到几十万的税。

### 财政补贴 / 引导基金
- 各级政府引导基金（国家、省、市、区）
- 产业引导基金（特定行业）
- 专精特新"小巨人"补贴
- 高新技术企业奖励
- 出海补贴（如跨境电商补贴）
- 节能改造补贴 / 绿色技改补贴
- 数字化转型补贴

**注意**：引导基金多以股权投资为主，需要让渡部分股权。补贴申请通常需要做项目策划 / 文书材料，专业服务可以代办。

### 政府采购 / 首台套 / 首批次政策
- 政府采购对自主创新产品优先
- 首台（套）重大技术装备 + 首批次（次）新材料 + 首版次软件保险补偿
- 政务大模型 / AI 应用 政府采购
- 央企 / 国企的"信创"采购
- 公立医院的"国产替代"采购

### 直接融资工具
- **科创板 / 创业板上市**
- **北交所 / 新三板**（中小企业友好）
- **债券市场"科技板"**（纲要新提，2025-2026 落地）
- **REITs**（基础设施、保障房、产业园区，常态化推荐发行）
- **并购基金 / 国家创业投资引导基金**
- **政策性银行贷款**（国开行、进出口银行、农发行）
- **专项再贷款**（科技、绿色、普惠）

### 监管沙盒
- **"沙盒监管"**（纲要新增表述）
- **"触发式监管"**（新模式）
- **海南自贸港金融创新**
- **粤港澳大湾区跨境数据流动试点**

## 三、合规成本变化

### 增加的合规成本
- **数据合规**：数据分类分级、数据出境安全评估、个人信息保护
- **AI 合规**：算法备案、生成内容标识、深度合成管理、训练数据合规
- **网络安全**：等保 2.0、关键信息基础设施保护、容灾备份
- **环保合规**：排污许可、碳排放报告、碳足迹核算（部分行业）
- **税务合规**：自然人税费监管加强、电子发票、税务大数据稽查
- **劳动合规**：新就业形态劳动者保护、平台用工合规
- **反垄断 / 反不正当竞争**：经营者集中申报、平台经济合规
- **跨境合规**：外商投资安全审查、出口管制、企业境外投资监管

### 减轻的合规成本
- **"高效办成一件事"**：政务服务整合
- **注册资本认缴登记**：进一步精简
- **涉企经营许可**：负面清单管理
- **"综合查一次"**：合并检查
- **信用承诺制**

**实际影响**：合规成本总体在上升，但程序便利在改善。建议中小企业**优先建立基本合规框架**（公司治理、税务、劳动、数据），不要冒险。

## 四、融资环境

### 当前融资环境的主要变化（基于纲要）
1. **直接融资比重提高**：股权融资 + 债券融资比例上升
2. **科技板债券**：为科技型中小企业开新通道
3. **耐心资本壮大**：长期资金（养老金、保险资金）入市政策完善
4. **政府引导基金 + 国家创业投资引导基金**：股权早期支持
5. **并购基金**：国家级并购基金作用强化
6. **REITs 常态化**：基础设施盘活
7. **外资股权投资便利化**

### 创业者融资策略建议

**早期阶段**（种子-A 轮）：
- 个人储蓄 + 亲友 + 天使投资人
- 政府引导基金（地方科创、产业、人才）
- 高新区/产业园区配套基金
- 风险投资机构（VC）

**成长期**（B-D 轮）：
- 风险投资 + 私募股权（PE）
- 战略投资人（产业资本）
- 银行科创贷款
- 知识产权质押
- 上市辅导启动

**成熟期**：
- 科创板 / 创业板 / 北交所上市
- 并购退出（被产业方收购）
- 老股转让

**注意事项**：
- 融资环境整体不如 2018-2021 年。VC 投资额已腰斩。
- 募资难、投资难、退出难是三难。
- 不要为了融资而融资 — 自己业务能造血才是王道。
- 关注政府引导基金（不容易要回报但相对容易拿到）和银行科创贷款。
- 估值要务实，不要被早期高估值套牢。

## 五、出海窗口

### 政策鼓励的出海方向
- **数字 + AI 出海**：纲要明确"鼓励互联网平台、人工智能等新兴产业企业拓展海外应用场景"
- **新能源全产业链**：电动车、电池、光伏、储能、绿氢
- **跨境电商**："丝路电商"合作先行区
- **专业服务**："咨询评估、法律服务、会计审计、信用评级、调解仲裁"等海外服务网络
- **绿色技术 / 节能环保 / 设备出口**
- **中国标准海外应用**：北斗、5G/6G、人民币支付

### 重点市场
- 东南亚（RCEP + 中国-东盟自贸区 3.0）
- 中东（沙特、阿联酋 — 战略合作深化）
- 拉美（巴西、墨西哥 — 跨境电商 + 制造业转移）
- 非洲（一带一路重点）
- 中亚（中欧亚班列）
- 部分欧洲（虽有摩擦，但市场仍大）

### 出海的实操建议

1. **不要为出海而出海**：出海是延伸不是逃避。国内做不好的，海外更难。
2. **本地化是核心**：产品、运营、团队、文化都要本地化，否则只是搬运。
3. **合规优先**：海外法律、税务、数据、劳动用工差异巨大。请专业服务。
4. **资金回流要规划**：境内境外资金通道、税务安排提前设计。
5. **关注海外仓 / 跨境物流 / 跨境支付的基础设施改善**：纲要明确推进。
6. **避免地缘高风险地区**：如制裁国、政局不稳国。
7. **善用国家级支持**：进博会、广交会、服贸会、"投资中国"品牌活动、驻外使领馆经商参赞处。

## 六、可能踩雷的领域

### 行业层面的雷
- **高耗能高排放新建项目**：碳排放等量/减量置换的硬约束
- **被"反内卷"整治的行业**：光伏、电池、汽车价格战、部分化工 — 中小企业先死
- **学科类校外培训**：彻底关闭
- **影子银行 / 非法金融活动**：高压打击
- **教培擦边球 + 直播带货虚假宣传** + 网红经济
- **房地产开发**：除特殊机会外不建议进入
- **传统媒体 / 部分内容平台**：监管成本高
- **重资产传统制造业（缺乏技术升级）**：被产业转移和环保挤压

### 操作层面的雷
- **税务不规范**：金税四期 + 大数据稽查越来越严
- **数据违规**：超范围采集、滥用、跨境流出
- **AI 内容违规**：生成色情、暴力、政治敏感内容
- **平台经济违规**：二选一、大数据杀熟、信息茧房
- **劳动用工违规**：新就业形态劳动者权益、加班、欠薪
- **环保违规**：偷排、超标
- **金融违规**：非法集资、变相吸储
- **股权激励税务处理不当**
- **跨境业务税务不当**

### 战略层面的雷
- **押注地方政府订单 / 城投平台业务**：地方债务压缩期回款难
- **依赖某一个大客户/平台**：政策一变就死
- **资金占用率过高 + 高杠杆**：周期下行扛不住
- **过度依赖低价竞争**：政策导向反内卷，价格战未来更被监管打压
- **核心技术依赖单一海外供应**：地缘风险

## 七、给创业者的元建议

1. **政策红利 ≠ 商业机会**。纲要写了的事不一定有市场，市场需要的事纲要也可能没写。
2. **政策红利吃头啖汤**：第一批进入的人享受补贴、税优、采购、舆论关注。但红利往往 18-24 个月就结束。
3. **政策风险也吃头啖汤**：第一批被监管的人会作为"典型案例"被严厉处理。
4. **不要赌政策延续**：5 年内政策可能调整。商业模式要在 *政策中性* 下也能盈利。
5. **借势但不依赖**：政府引导基金、补贴是助力，不是核心商业逻辑。
6. **合规是护城河**：早期看似成本，长期看是壁垒。
7. **本地资源 + 全国市场 + 全球视野**：中国市场仍是最大的，但 5 年视角必须有出海备份。
8. **现金为王**：经济周期下行期，活下来比扩张更重要。

## 附：5 个可以马上做的小动作（如果你正在或打算创业）

1. 复核你的公司是否能申请高新技术企业认定（所得税 15%）
2. 检查研发费加计扣除是否充分用足
3. 评估个人养老金 + 商业保险作为创始人的个人风险对冲
4. 了解本地（市/区）的产业引导基金和政府采购清单
5. 评估你的业务是否有出海延伸的可能 — 哪怕只是一个海外样板客户
